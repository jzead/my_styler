# 요구사항과 제약 조건

## 기능 요구사항
- 옷 정보와 사진을 등록·조회·수정·삭제한다.
- 옷 정보에 따라 스타일을 추천할 수 있어야 한다. (이후 기능)

## 품질 목표
- 터치 화면에서 정보를 쉽게 입력하고 선택할 수 있어야 한다.
- 목표 기기에서 원활하게 동작해야 한다. (기기와 성능 기준은 추후 결정)

## 제약 조건
- Python을 사용한다.
- 첫 실행 환경은 Android 테블릿(S7 FE)를 기준으로 개발한다.
- 안드로이드 버전 14

## 아키텍처에 영향을 주는 조건
- 터치 조작이 주요 입력 방식이다.
- Android와 Python을 함께 사용할 방법을 정해야 한다.
- 이후 실제 옷장 하드웨어에 연결할 가능성이 있다.

## 확정된 기술 및 구조 결정
- 대상 기기: Samsung Galaxy Tab S7 FE
- 대상 OS: Android 14
- UI 프레임워크: Kivy
- 앱 구조: 태블릿 단독 실행
- 첫 버전: 옷 정보와 사진의 등록·조회·수정·삭제
- 저장 방식: 태블릿 내부에 데이터를 저장
- 사진 처리: 사진 파일과 데이터베이스를 분리하고, DB에는 사진 경로를 저장

## 아직 결정하지 않은 사항
- UI 프레임워크와 라이브러리
- 파일과 폴더 구조
- 사진 저장 방식
- 스타일 추천을 첫 버전에 포함할지 여부
